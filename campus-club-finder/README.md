# Campus Club Finder
A responsive student club discovery SPA using React, Vite, React Router v7, Tailwind CSS v4 and localStorage.

## Run locally
Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```
Open the URL shown in the terminal. Use `npm run build` for production and `npm run preview` to preview the build.

## Features
Five sample clubs, alphabetical sorting, grid/list view, detail pages with events, persistent club membership, About and 404 pages. No backend or authentication. Sample events are fictional. Membership is specific to the browser and origin.

See [DOCUMENTATION.md](DOCUMENTATION.md) for the walkthrough and screenshot checklist. BrowserRouter requires a host that rewrites unknown routes to index.html if deploying a live demo.
